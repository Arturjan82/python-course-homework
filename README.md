# Учебные задания по Python

Домашние задания, которые я выполнял при обучении Python. Каждая папка соответствует одному заданию (модулю), код оставлен как есть, без полировки: это путь обучения, а не готовые проекты.

## Темы
- классы и ООП (большая часть заданий);
- работа с файлами и обработка исключений (`open`, `try/except`);
- потоки и процессы: `threading`, `multiprocessing`;
- модульное тестирование: `unittest` (модуль 12);
- интроспекция: `inspect`;
- HTTP-запросы: `requests` (модуль 11);
- асинхронность: `asyncio` и основы Telegram-ботов на `aiogram` (модуль 13).

## Ключи и секреты
В заданиях нет рабочих ключей: токены ботов заменены заглушками, ключ внешнего API хранится в отдельном файле, которого в репозитории нет.
